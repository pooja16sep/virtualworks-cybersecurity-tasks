## Task 1: Password Strength Checker

Checks how strong a password is and gives tips to improve it.

**What it checks:**
- Length (8+ and 12+ characters)
- Lowercase, uppercase, numbers and special characters
- Common passwords (like "password" or "123456")
- Repeated characters (like "aaa")

**Result:** Weak, Medium or Strong, with a score out of 6.

**How to run:**
python password_checker.py

Enter a password when asked. Type `q` to quit.
